# 🧪 Sprint 7 — API-тесты сервиса «Самокат»

## 📋 Описание проекта
Проект содержит автоматизированные тесты API для сервиса **Яндекс Самокат**.  
Тесты проверяют корректность работы основных ручек backend-приложения: создание курьера, авторизация, создание заказа, получение заказа, принятие заказа и т.д.

Все тесты написаны на **Python + Pytest** с использованием **Allure** для формирования отчётов.

---

## 🧰 Технологии
- Python 3.13  
- Pytest  
- Requests  
- Allure-pytest
